# Indu Fortune Fields Gardenia Apartments (IFFGAOA)
### Community Amenities & Facilities Portal

A production-grade, responsive modern web application showcasing the amenities, infrastructure, sports facilities, and holistic development programs at **Indu Fortune Fields Gardenia Apartments (IFFGAOA)** in KPHB Colony, Phase 13, Kukatpally, Hyderabad - 500085, Telangana.

---

## 🛠️ Interactive Capabilities

1. **Instant Search:** Live keyword search across all facilities, services, and operating hours.
2. **Category Filter Engine:** Instant chip filtering with dynamic count badges for Sports, Wellness, Convenience, and Campus.
3. **Facility Reservation & Enrolment Engine:** Interactive modal generating resident booking passes with `localStorage` persistence.
4. **My Reservations Passbook:** Track, view, and manage active booking passes.
5. **Emergency & Quick Directory Drawer:** One-tap dialing for Security Intercom (#100), Gas Emergency (#102), Power Plant (#104), and Society Office.
6. **Operating Hours Matrix:** Live schedule with real-time operational status badges.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser, or launch a local web server:

```bash
# Python 3
python -m http.server 3000

# Node.js (npx)
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
